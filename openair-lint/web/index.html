OpenAir Validator

Checks OpenAir airspace files against the OpenAir 3.0 file format specification by Naviter.

About this page

This page checks the header, the airspace attributes (AC, AY, AN, AF, AG, AS, AX), the altitude limits (AH, AL), the activation times (AA) and the geometry (DP, DA, DB, DC, DY, V). It shows each problem with the line, the column and a link to the rule in the specification. Some problems have an automatic fix: the page can fix them, and you can download the fixed file.

  • Error: the file breaks a "must" rule of the specification.
  • Warning: the file breaks a "should" rule.
  • Info: a hint about style. The file is still valid.

Your file stays on your computer. The check runs in your browser. The file is not uploaded anywhere. This page makes no network requests and has no analytics.

OpenAir 3.0 is a draft, and this validator is a development version. Rules and messages can change.
